This document is divided into 2 parts:  
1. Explanation of Story JSON Rules  
2. Example JSON Parsing  

Note:  
1. Unless otherwise specified, all file paths should be relative paths starting from the location of the JSON file.  



1. Explanation of Story JSON Rules:  
Top-level keys: "settings", "ui", "story_and_position"

"settings": dictionary (required)  
    Description: Used to configure language support, window size, title, etc.  
    Keys inside "settings": "language", "window_size", "window_title", "identify_code"  
    
    "language": list (required)  
        Explanation of elements in "language": The list contains language tags that are supported, e.g., ["zh", "en", "ru"].  
    
    "window_size": string (optional)  
        Explanation of "window_size": Specifies the window dimensions in the format "<width>x<height>", e.g., "1280x720".  
    
    "window_title": string (optional)  
        Explanation of "window_title": Sets the game window title. If not provided, defaults to "GalPie".  
    
    "identify_code": string (optional)  
        Explanation of "identify_code": Sets an identification code for this story, used to manage story save files more conveniently.

"ui": dictionary (theoretically required)  
    Description: Used to configure interactive UI elements, such as dialogue boxes.  
    Keys inside "ui": "chatbox_and_words_position"  
    
    "chatbox_and_words_position": dictionary (theoretically required)  
        Description: Configuration for dialogue box appearance.  
        Keys inside "chatbox_and_words_position": "chatbox", "name_show_region", "words_show_region"  
        
        "chatbox": string (required)  
            Explanation of "chatbox": Specifies the storage path (relative to the JSON file) of the dialogue box image, e.g., "./res/ui/chatbox.png".  
        
        "name_show_region": list (required)  
            Explanation of elements in "name_show_region": The list contains two sublists representing the top-left and bottom-right coordinates of the area where the speaker's name appears within the dialogue box. Coordinates are based on the "chatbox" image, with the top-left corner as origin (0,0), x-axis increasing rightward, y-axis increasing downward. Format example: [[76,60],[270,149]] means the name display region spans from pixel (76,60) to (270,149) on the chatbox image.  
        
        "words_show_region": list (required)  
            Explanation of elements in "words_show_region": Similar to "name_show_region", the list contains two sublists representing the top-left and bottom-right coordinates of the subtitle display area within the dialogue box. Coordinates follow the same system as above. Format example: [[310,60],[805,149]] defines the subtitle region from (310,60) to (805,149) on the chatbox image.

"story_and_position": dictionary (required)  
    Description: Configures story content, characters, backgrounds, etc.  
    Keys inside "story_and_position": "character_and_motion", "backgrounds", "story"  
    
    "character_and_motion": dictionary (required)  
        Description: Defines characters with visual representations.  
        Keys inside "character_and_motion": Custom character tags, e.g., "girl", "congyu", "丛雨"  
        
        <character_tag>: dictionary (required)  
            Keys inside the character tag: "name", "form", "face"  
            
            "name": dictionary (required)  
                Description: Sets the in-game display name for this character.  
                Keys inside "name": Language tags defined in "settings" → "language", e.g., if "language" is ["zh", "en", "jp"], then this dictionary should be: {"zh": "丛雨", "en": "Murasame", "jp": "ムラサメ"}  
                
                <language_tag>: string (required)  
                    Explanation: The character's display name in the corresponding language.  
            
            "form": dictionary (required)  
                Description: Defines different visual forms (outfits/poses) for the character and their associated image paths.  
                Keys inside "form": Custom form tags, e.g., "校服", "工作", "校服2"  
                
                <form_tag>: string (required)  
                    Explanation: File path to the image for this form, e.g., "校服": "./res/character/girl/uniform.png"  
            
            "face": dictionary (optional)  
                Description: Defines facial expressions and their image paths. Alternatively, you may embed expressions directly into form images and skip this section.  
                Keys inside "face": Custom expression tags, e.g., "微笑", "脸红", "平常"  
                
                <expression_tag>: string (required)  
                    Explanation: File path to the expression image, e.g., "脸红": "./res/character/girl/shy.png"  
    
    "backgrounds": dictionary (required)  
        Description: Defines background labels and their image paths.  
        Keys inside "backgrounds": Custom background tags, e.g., "学校", "教室", "公园"  
        
        <background_tag>: string (required)  
            Explanation: File path to the background image, e.g., "公园": "./res/bg/park.png"  
    
    "storyline_id": dictionary (required)  
        Description: Defines storyline identifiers.  
        Keys inside "storyline_id": Custom storyline tags  
        
        <storyline_tag>: float (required)  
            Explanation: The value determines which storyline is active. At startup and branching points, the program compares all storyline values and automatically enters the one with the highest value. For example, {"main": 1.0, "girl": 0.5} will start with the "main" storyline. Values can be adjusted during gameplay. Avoid having two or more storylines share the same maximum value; if this occurs, no new storyline will be entered. See Part 2 for usage examples.  
    
    "story": dictionary (required)  
        Description: Contains the actual story content for each storyline.  
        Keys inside "story": Storyline tags defined in "storyline_id"  
        
        <storyline_tag>: dictionary (required)  
            Description: Story scenes, settings, subtitles, etc. Note: When "clear_all": false, scene elements from the previous page persist unless explicitly redefined—redefining replaces the entire content of that element. See Part 2 for examples.  
            Keys inside this dictionary: Page numbers, starting from 1  
            
            <page_number>: list (required)  
                Description: Defines scenes on this page.  
                Elements in the list: Each element is a dictionary; n elements mean n scenes (n ≥ 1).  
                
                List element: dictionary (required)  
                    Description: Scene configuration.  
                    Keys inside the dictionary: "clear_all", "change", "bg", "characters", "content", "edit_storylineID_value"  
                    
                    "clear_all": bool (theoretically required)  
                        Description: Whether to clear all content from the previous page. true = yes, false = no.  
                    
                    "change": string (optional)  
                        Explanation of "change": Specifies transition effect. Default is instant change.  
                        Currently supported effects:  
                            Fade-in/out: "gradient"  
                    
                    "bg": string (optional)  
                        Explanation of "bg": Specifies background using a label from "backgrounds", e.g., "bg": "公园"  
                    
                    "characters": dictionary (optional)  
                        Description: Brings visual characters onto the scene.  
                        Keys inside "characters": Character tags from "character_and_motion"  
                        
                        <character_tag>: dictionary (required)  
                            Description: Configures the character’s form, position, expression, zoom, animation, etc.  
                            Keys inside: "form", "pos", "face", "zoom", "animate"  
                            
                            "form": string (required)  
                                Explanation: Form label defined under this character’s "form" in "character_and_motion".  
                            
                            "pos": list (required)  
                                Explanation: Two values for x and y coordinates placing the character image on the background. Origin is top-left of background (0,0), x increases rightward, y downward. Format: [320,80] places the character at (320,80) on the background.  
                            
                            "face": list (theoretically required)  
                                Explanation: Two elements: first is an expression label from this character’s "face"; second is a list of x,y offsets placing the expression image on the character’s form image (origin top-left of form image). Example: ["脸红",[0,0]]  
                            
                            "zoom": float (optional)  
                                Explanation: Character scale factor. Default is 1.0; <1.0 shrinks, >1.0 enlarges.  
                            
                            "animate": list (optional)  
                                Description: Animations for this character in this scene.  
                                Elements: Each is a dictionary; n elements = n animations played sequentially.  
                                
                                List element: dictionary (required)  
                                    Keys: "time", "zoom", "move"  
                                    
                                    "time": float (required)  
                                        Explanation: Animation duration in seconds.  
                                    
                                    "zoom": float (optional)  
                                        Explanation: Target zoom value. Over the animation duration ("time"), zoom interpolates from current value to this value. See Part 2 for examples.  
                                    
                                    "move": list (optional)  
                                        Explanation: Sequence of relative movements. Each sublist contains [dx, dy] (x right+, y down+). Over "time", the character moves through these offsets sequentially. Example: [[-10,0],[0,10],[10,0],[0,-10]] moves left 10, down 10, right 10, up 10.  
                    
                    "content": dictionary (required)  
                        Description: Dialogue content.  
                        Keys: "speaking"/"speaking_name", "words"  
                        
                        "speaking": dictionary / "speaking_name": string (choose one, but one is required)  
                            "speaking" explanation: Sets speaker name per language. See Part 2 for examples.  
                            Keys in "speaking": Language tags from "settings" → "language"  
                            
                            <language_tag>: string (required)  
                                Explanation: Speaker name in this language.  
                            
                            "speaking_name" explanation: If the speaker is defined in "character_and_motion", use their character tag here.  
                            "speaking_name" content: A character tag from "character_and_motion".  
                        
                        "words": dictionary (required)  
                            Description: Subtitle text per language. See Part 2 for examples.  
                            Keys in "words": Language tags from "settings" → "language"  
                            
                            <language_tag>: string (required)  
                                Explanation: Subtitle text in this language.  
                    
                    "edit_storylineID_value": dictionary (optional)  
                        Description: Adjusts values in "storyline_id".  
                        Keys: Storyline tags from "storyline_id"  
                        
                        <storyline_tag>: list (required)  
                            Explanation: Two elements: first is operation ("replace" or "add"); second is value. Example: "girl": ["add", -0.2] subtracts 0.2 from the current "girl" storyline value.  
                    
                    "check_storyline": bool (optional)  
                        Description: If true, after this scene, the program checks storyline values and enters the one with the highest value. If false, nothing happens.
