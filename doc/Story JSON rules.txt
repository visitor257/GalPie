1. Explanation of the story JSON rules.
2. Example JSON parsing.

Note:
1. Unless otherwise specified, all file paths filled in should be relative paths starting from the location of the JSON file.

1. Explanation of the story JSON rules:
Top-level keys: "settings", "ui", "story_and_position" (all are required unless stated otherwise).

"settings": dictionary (Required)
    Description: Used to set language support, window size, title, etc.
    Keys within "settings": "language", "window_size", "window_title"

    "language": list (Required)
        Explanation of elements within "language": The list contains tags for the supported languages, e.g.: ["zh", "en", "ru"].

    "window_size": string (Optional)
        Explanation of "window_size" content: Sets the window size. Format is "<width>x<height>", e.g.: "1280x720".

    "window_title": string (Optional)
        Explanation of "window_title" content: Sets the game window title. If not filled, defaults to "GalPie".
    
    "identify_code": string（Optional）
        Explanation of "identify_code" content: Sets the identify code of this story. Use for better management of the saves of this story.

"ui": dictionary (Theoretically Required)
    Description: Used to set up the interactive interface, such as the dialog box.
    Keys within "ui": "chatbox_and_words_position"

    "chatbox_and_words_position": dictionary (Theoretically Required)
        Description: Settings for the dialog box style.
        Keys within "chatbox_and_words_position": "chatbox", "name_show_region", "words_show_region"

        "chatbox": string (Required)
            Explanation of "chatbox" content: The storage location of the dialog box style (should be an image). The filled path should be a relative path starting from the JSON file's location, e.g.: "./res/ui/chatbox.png".

        "name_show_region": list (Required)
            Explanation of elements within "name_show_region": The list should contain two lists. These two lists represent the top-left and bottom-right coordinates of the speaker's name display area within the dialog box. The coordinate system is based on the dialog box style image ("chatbox"), with the top-left corner of the image as point (0,0), the x-axis increasing to the right, and the y-axis increasing downward. Format example: [[76,60],[270,149]] means using the area from pixel (76, 60) as top-left to pixel (270, 149) as bottom-right on the dialog box style image as the display region for the speaker's name.

        "words_show_region": list (Required)
            Explanation of elements within "words_show_region": Similar to "name_show_region". The list should contain two lists representing the top-left and bottom-right coordinates of the subtitle display area within the dialog box. Coordinate system is based on the dialog box style image. Format example: [[310,60],[805,149]] means using the area from pixel (310, 60) to pixel (805, 149) as the subtitle display region.

"story_and_position": dictionary (Required)
    Description: Sets the story content, characters, backgrounds, etc.
    Keys within "story_and_position": "character_and_motion", "backgrounds", "story"

    "character_and_motion": dictionary (Required)
        Description: Defines characters with appearances.
        Explanation of keys within "character_and_motion": Custom character tags, e.g.: "girl", "congyu", "丛雨".

        <Character Tag>: dictionary (Required)
            Keys within the character tag: "name", "form", "face"

            "name": dictionary (Required)
                Description: Sets the name/title for this character tag in the game.
                Explanation of keys within "name": These are the language tags set in "settings" -> "language". For example, if "language" is set to ["zh", "en", "jp"], this dictionary should contain: {"zh": "丛雨", "en": "Murasame", "jp": "ムラサメ"}.

                <Language Tag>: string (Required)
                    Content explanation: The name/title of the character in the language corresponding to the language tag.

            "form": dictionary (Required)
                Description: Sets the different forms (outfits/states) for this character and the image file path associated with each form.
                Explanation of keys within "form": Custom form tags, e.g.: "校服" (School Uniform), "工作" (Work), "校服2".

                <Form Tag>: string (Required)
                    Content explanation: The image file path associated with this form tag. e.g.: "校服": "./res/character/girl/uniform.png".

            "face": dictionary (Optional)
                Description: Sets the facial expressions for this character and the associated image file paths. You can also include expressions directly on the form image and call that form in the story later, thus omitting this section.
                Explanation of keys within "face": Custom expression tags, e.g.: "微笑" (Smile), "脸红" (Blush), "平常" (Normal).

                <Expression Tag>: string (Required)
                    Content explanation: The image file path associated with this expression tag. e.g.: "脸红": "./res/character/girl/shy.png".

    "backgrounds": dictionary (Required)
        Description: Sets tags for different backgrounds and their associated image file paths.
        Explanation of keys within "backgrounds": Custom background tags, e.g.: "学校" (School), "教室" (Classroom), "公园" (Park).

        <Background Tag>: string (Required)
            Content explanation: The image file path associated with this background tag. e.g.: "公园": "./res/bg/park.png".

    "story": dictionary (Required)
        Description: The story content and scene settings (background, characters, dialog). Note: If "clear_all": false, elements from the previous page's scene will persist unless explicitly changed. If an element is reset, its content will be completely replaced by the new settings. Details can be understood in the example JSON parsing in Part 2.
        Explanation of keys within "story": Page numbers, starting from 1.

        <Page Number>: list (Required)
            Description: Sets the scenes for this page.
            Explanation of list elements: Each element is a dictionary. Having n elements (dictionaries) in the list means there are n scenes (n must be at least 1).

            Element within the list: dictionary (Required)
                Description: Settings for a scene.
                Keys within the dictionary: "clear_all", "change", "bg", "characters", "content".

                "clear_all": bool (Theoretically Required)
                    Description: Whether to clear all content from the previous page's scene. true for yes, false for no.

                "change": string (Optional)
                    Explanation of "change" content: Sets the transition effect. Default is an immediate change.
                    Currently supported effects:
                        Gradient/Fade: "gradient".

                "bg": string (Optional)
                    Explanation of "bg" content: Sets the background. The content should be a background tag defined above in "backgrounds". e.g.: "bg": "公园".

                "characters": dictionary (Optional)
                    Description: Places characters with appearances on the stage.
                    Explanation of keys within "characters": These are the character tags defined above in "character_and_motion".

                    <Character Tag>: dictionary (Required)
                        Description: Sets the form, position, expression, zoom, animation, etc., for the character appearing on stage.
                        Keys within the dictionary: "form", "pos", "face", "zoom", "animate".

                        "form": string (Required)
                            Explanation of "form" content: This should be a form tag defined within this character's "form" dictionary in "character_and_motion".

                        "pos": list (Required)
                            Explanation of elements within "pos": The list should contain two values, corresponding to the x and y coordinates where the form image will be placed on the background image. The coordinate system is based on the background image, with the top-left corner as (0,0), x increasing right, y increasing down. Format example: [320,80] means placing the form image at pixel (320, 80) on the background image.

                        "face": list (Theoretically Required)
                            Explanation of elements within "face": Contains two elements. The first is a string, which is the expression tag defined in this character's "face" dictionary. The second is a list containing two values, the x and y coordinates where the expression image will be placed on the form image. The coordinate system is based on the form image. Format example: [0,0] means placing the expression image at (0, 0) on the form image. The full list format is: ["脸红",[0,0]].

                        "zoom": float (Optional)
                            Explanation of "zoom" value: Sets the character's zoom scale. Default is 1.0. Values less than (<) 1.0 shrink, greater than (>) 1.0 enlarge.

                        "animate": list (Optional)
                            Description: Sets animations for the character within this scene.
                            Explanation of list elements: Each element is a dictionary. Having n elements means n animations. Animations play sequentially.

                            Element within the list: dictionary (Required)
                                Keys within the dictionary: "time", "zoom", "move".

                                "time": float (Required)
                                    Explanation of "time" value: The duration of the animation in seconds.

                                "zoom": float (Optional)
                                    Explanation of "zoom" value: Sets a zoom animation. Over the animation duration ("time"), the character's zoom will change from the initial "zoom" value (set above for the character) to this value. See the example JSON parsing in Part 2 for details.

                                "move": list (Optional)
                                    Explanation of "move" content: The elements are lists. There is no strict upper limit to the number of inner lists. Each inner list contains two numerical values, corresponding to relative x and y coordinates (relative to the character's current position). The x-axis increases right, y-axis down. Over the animation duration ("time"), the character will move sequentially to these relative coordinates. Example: To move the character left 10, then down 10, then right 10, then up 10, you would input: [[-10,0],[0,10],[10,0],[0,-10]].

                "content": dictionary (Required)
                    Description: Sets the dialog content.
                    Keys within "content": "speaking"/"speaking_name", "words".

                    "speaking": dictionary / "speaking_name": string (Choose one, either is required)
                        "speaking" description: Sets the speaker's name for each language tag. See the example JSON parsing in Part 2 for details.
                        Explanation of keys within "speaking": These are the language tags set in "settings" -> "language".

                        <Language Tag>: string (Required)
                            Content explanation: The speaker's name in the language corresponding to the language tag.

                        "speaking_name" description: If the speaker is defined in "character_and_motion", you can directly use the character tag here.
                        Explanation of "speaking_name" content: A character tag defined in "character_and_motion".

                    "words": dictionary (Required)
                        Description: Sets the dialog subtitle for each language tag.
                        Explanation of keys within "words": These are the language tags set in "settings" -> "language".

                        <Language Tag>: string (Required)
                            Content explanation: The dialog subtitle in the language corresponding to the language tag.

        "form": {                                               <- Set form tags, i.e., character's forms/styles

        "content": {
          "speaking_name": "girl",                                      <- Speaker setting. If the character is defined in "character_and_motion", use "speaking_name" and fill in the character tag.
          "words": {
            "zh": "Hello, is this seat taken?"

        "bg": "公园",                         <- Background set to "公园", a tag defined in "backgrounds".

          "girl": {                         <- Key is the character tag defined in "character_and_motion"
            "form": "校服",                   <- Set form, use a form tag defined for this character.
            "pos": [320,80],                <- Set the position of the form image on the background. List contains x and y coordinates on the background image (top-left is 0,0). Here, place at (320, 80).
            "face": ["平常",[0,0]],           <- Set expression and its position. First element is the expression tag ("平常"). Second element is the coordinates [x,y] for placing the expression image on the form image (top-left of form is 0,0). Here, place at (0,0).
