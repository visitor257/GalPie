本文档分为2部分：
1. 剧情json规则解释
2. 示例json解析

注意：
1. 若无特别指名，所有填写的文件路径应为从json文件所在位置开始的相对路径。

本文档基于当前 story/sample_create.json 的实际内容与代码实现整理，替代旧版规则。
未实现的字段（如场景内的 edit_storylineID_value / check_storyline）已从规则中移除或标注"预留"。



1. 剧情json规则解释：
首级keys："settings", "ui", "menu", "story_and_position"

"settings": 字典（选填，缺失时使用默认值）
    说明：用于设置语言支持、窗口大小、标题等。缺失或为空时程序使用默认值（语言回退 "zh"、窗口 1280x720、标题 "GalPie"）。
    "settings"内的keys："language", "window_size", "window_title", "identify_code", "transition_color", "default_audio_lang_id"

    "language": 字典（选填，缺失时默认 "zh"）
        说明：设置所支持的语言。当前格式为字典：{语言标签: 语言显示名称}。
        程序取字典中第一个语言标签作为初始语言。缺失或为空时程序使用 "zh" 作为当前语言。
        "language"内的keys说明：为语言标签，如："zh", "en", "ja", "ru"
        例如：{"zh": "中文", "en": "English", "ja": "日本語", "ru": "Русский"}
        兼容旧格式：也可填写列表 ["zh", "en", "ru"]，程序取第一个作为初始语言。

    "window_size": 字符串或列表（选填）
        说明：设定窗口大小。可为单个分辨率字符串（旧格式），或分辨率字符串列表（新格式，index=0 为初始分辨率）。
        字符串格式为"<宽>x<高>"，如："1280x720"。
        列表格式如：["1280x720", "1600x900", "1920x1080"]，列表中的选项会出现在设置面板的分辨率下拉框中。
        若不填写，则默认为"1280x720"。

    "window_title"：字符串（选填）
        "window_title"的内容解释：设置游戏窗口的标题。若不填写，则默认为"GalPie"。

    "identify_code": 字符串（选填）
        "identify_code"的内容解释：设置此剧情的识别码，用于更方便管理剧情存档文件。

    "transition_color"：列表（选填，默认 [0, 0, 0] 黑色）
        "transition_color"的内容解释：设置转场过渡期间窗口显示的颜色，RGB格式，三个0~255的整数，如：[0, 0, 0]。
        程序在以下转场场景使用此颜色作为过渡色块：
        - 点击"开始游戏"后：主菜单渐隐，先渐变成此颜色，停留约1.5秒，再渐变进入剧情。
        - 从主菜单确认读档后：同样先渐变成此颜色，再渐变进入读档场景。
        - 空白/清空场景（无任何元素）时，窗口底色亦为此颜色。

    "default_audio_lang_id"：字符串（选填）
        "default_audio_lang_id"的内容解释：音频回退语言标签。当场景音频（audio）的当前语言文件缺失时，回退使用此语言标签对应的音频文件（仅对 json_mode=judge 的音频生效，见下方场景级 audio 说明）。缺省时不回退（当前语言无文件则不播放）。

"ui": 字典（选填，缺失时使用默认UI）
    说明：用于设置交互界面，如对话框、底部菜单。缺失时使用默认UI设置（默认对话框样式/名字区域/字幕区域）。
    "ui"内的keys："confirm_ui", "chatbox_and_words_position", "bottom_menu"

    "confirm_ui": 字典（选填，缺省时使用默认确认框外观）
        说明：确认框（confirm dialog）的界面配置。确认框用于需要二次确认的操作：主菜单"继续游戏"（menu_pos.qload）确认读档、底部菜单"Q.Load"（快速加载）确认读档、主菜单"退出游戏"（menu_pos.quit）确认退出。
        确认框由全屏遮罩（颜色取 settings.transition_color，透明度 50%）+ 居中圆角确认框组成，内容为一行问题文字 + 两个按钮（取消/确认）。
        "confirm_ui"内的keys："ui_mode", "color", "text_color", "cancel_color", "confirm_color"

        "ui_mode"：字符串（选填）
            "ui_mode"的内容解释：界面模式，目前仅支持 "default"（预设样式）。

        "color"：列表（选填，默认 [255, 255, 255, 217]）
            "color"的内容解释：确认框底色，RGBA格式。

        "text_color"：列表（选填，默认 [30, 30, 30]）
            "text_color"的内容解释：问题文字（如"确认？"）的颜色，RGB格式。

        "cancel_color"：列表（选填，默认 [255, 255, 255]）
            "cancel_color"的内容解释："取消"按钮的底色，RGB格式。文字颜色按亮度自动选择（规则同底部菜单 button_color）。

        "confirm_color"：列表（选填，默认 [30, 30, 30]）
            "confirm_color"的内容解释："确认"按钮的底色，RGB格式。文字颜色按亮度自动选择。

    "chatbox_and_words_position": 字典（选填，缺省时使用默认对话框样式与区域）
        说明：对话框样式的设置。缺省时使用默认对话框样式/名字区域 [[76,60],[270,149]]/字幕区域 [[310,60],[805,149]]。
        其内部五个 key 均为选填，缺省各自使用默认值。
        "chatbox_and_words_position"内的keys："chatbox", "text_color", "readed_text_color", "name_show_region", "words_show_region"

        "chatbox": 字符串（选填，缺省时使用默认对话框样式）
            "chatbox"的内容解释：对话框样式（应为图片）的储存位置，填写的应为从json文件所在位置开始的相对路径，如："./res/ui/chatbox.png"

        "text_color"：列表（选填，默认 [255, 255, 255] 白色）
            "text_color"的内容解释：未读文本（首次播放的台词）的颜色，RGB格式，三个0~255的整数，如：[255, 255, 255]。

        "readed_text_color"：列表（选填，默认 [255, 255, 255] 白色）
            "readed_text_color"的内容解释：已读文本（已播放过的场景台词）的颜色，RGB格式，三个0~255的整数，如：[255, 255, 0]。
            程序根据已读记录（.gpreaded）判断当前场景是否已读：已读场景的台词用此颜色，未读场景的台词用上方"text_color"。

        "name_show_region"：列表（选填，缺省时使用默认区域 [[76,60],[270,149]]）
            "name_show_region"内的元素解释：列表内应有两个列表，两个列表分别代表对话框内说话人名字显示区域的左上角坐标和右下角坐标，坐标系基于对话框样式"chatbox"的图片，图片左上角为0点，x轴像右增加，y轴向下增加，格式如此：[[76,60],[270,149]]，代表以对话框样式（图片）上，位于(76, 60)的像素为左上，位于(270, 149)的像素为右下的区域作为说话人名字的显示区域。

        "words_show_region"：列表（选填，缺省时使用默认区域 [[310,60],[805,149]]）
            "words_show_region"内的元素解释：类似于"name_show_region"，列表内应有两个列表，两个列表分别代表对话框内字幕显示区域的左上角坐标和右下角坐标，坐标系基于对话框样式"chatbox"的图片，图片左上角为0点，x轴像右增加，y轴向下增加，格式如此：[[310,60],[805,149]]，代表以对话框样式（图片）上，位于(310, 60)的像素为左上，位于(805, 149)的像素为右下的区域作为字幕的显示区域。

    "bottom_menu": 字典（选填）
        说明：设置剧情中的底部菜单条。不填写则不显示底部菜单条。
        "bottom_menu"内的keys："mode", "color", "button_color", "backlog_bgcolor", "save"

        "mode"：字符串（选填）
            "mode"的内容解释：底部菜单的模式，目前仅支持 "default"（预设样式）。
            default 模式：在窗口底部显示一条半透明菜单条，右侧从右到左依次为"⊙"按钮、"日志"按钮、"设置"按钮、"快进(▷▷)"开关、"自动播放(▷)"开关、"加载"按钮、"保存"按钮、"快速加载(Q.Load)"按钮、"快速保存(Q.Save)"按钮。
            "⊙"按钮为隐藏开关：按下后对话框与底部菜单（含菜单条本身）全部消失，剧情照常推进；再按任意位置（左键或右键）恢复显示，对话框按进入隐藏前的可见性恢复（若剧情中对话框原本就隐藏，如过场页，则恢复后仍隐藏）。
            设置按钮打开设置面板；日志按钮打开日志面板；保存按钮打开保存面板；加载按钮打开加载面板（与主菜单"加载存档"一致）；快速保存按钮直接保存到快速存档槽；快速加载（Q.Load）按钮弹出确认框（外观取 ui.confirm_ui），确认后读取最新存档（同 F3）。
            在设置/日志/保存/加载任一面板打开时，按鼠标右键相当于点击该面板的"返回"按钮，直接关闭面板。
            （F2=存档、F3=读最新档、A=自动播放、S=快进）
            快进与自动播放互斥，打开其一自动关闭另一个；打开设置/日志/保存面板时两者会暂停，返回剧情后继续。

        "color"：列表（选填）
            "color"的内容解释：底部菜单条的填充颜色，RGBA格式，四个0~255的整数，如：[0, 0, 0, 200]。
            默认值为 [0, 0, 0, 255]。


        "button_color"：列表（选填）
            "button_color"的内容解释：底部菜单条上按钮（日志/设置/快进/自动播放/保存/快速保存）的底色，RGBA格式，如：[0, 0, 0, 200]。
            默认值为 [0, 0, 0, 255]。按钮文字颜色根据此颜色亮度自动选择：
            - RGB 三值之和 < 383：正常态白字，悬停时按钮变白底、文字变黑。
            - RGB 三值之和 ≥ 383：正常态黑字，悬停时按钮变黑底、文字变白。

        "backlog_bgcolor"：列表（选填）
            "backlog_bgcolor"的内容解释：日志（backlog）面板的背景色，RGBA格式，如：[255, 255, 255, 200]。
            默认值为 [255, 255, 255, 200]。

        "save"：字典（选填）
            说明：保存面板/加载面板的界面配置。保存面板与加载面板共用此结构（主菜单的加载按钮另有自己的配置，见下方 "menu_pos.load"）。
            "save"内的keys："ui_mode", "color", "saves_color", "saves_text_color", "text_color", "button_color"

            "ui_mode"：字符串（选填）
                "ui_mode"的内容解释：界面模式，目前仅支持 "default"（预设样式）。

            "color"：列表（选填，默认 [255, 255, 255, 217]）
                "color"的内容解释：面板背景色，RGBA格式。

            "saves_color"：列表（选填，默认 [185, 122, 87, 255]）
                "saves_color"的内容解释：存档格子（槽位）的底色，RGBA格式。悬停时按亮度自动变亮/变暗（保留原色调）：RGB 三值之和 < 383 时向白色混合 35%，≥ 383 时向黑色混合 35%。

            "saves_text_color"：列表（选填，默认 [255, 255, 255]）
                "saves_text_color"的内容解释：存档格子内文字的颜色（台词/日期时间/垃圾桶图标/空档"SAVE"字样/确认文案），RGB格式。
                注意：确认/取消按钮的文字固定为白色，不受此配置影响。

            "text_color"：列表（选填，默认 [30, 30, 30]）
                "text_color"的内容解释：面板内静态文字的颜色（左上角"保存游戏"/"加载游戏"标题、底部页数数字等），RGB格式。

            "button_color"：列表（选填，默认 [0, 0, 0, 255]）
                "button_color"的内容解释：面板底部工具条按钮（◀ 翻页 ▶、+ 加页、主菜单、返回）的底色，RGBA格式。文字/悬停规则同底部菜单条的 button_color（亮度 < 383 白字/悬停变白底黑字；≥ 383 黑字/悬停变黑底白字）。

"menu": 字典（选填）
    说明：设置主菜单（开始界面）。不填写则启动后直接进入剧情（从当前故事线第一页开始播放），不显示主菜单。
    填写则启动后先显示主菜单，点击"start"按钮后才进入剧情。
    "menu"内的keys："bg", "bgm", "change", "title", "button", "button_touched", "text_rgb", "menu_pos"

    "bg"：字符串（选填）
        "bg"的内容解释：主菜单背景图片路径（相对json），如："./res/menu/bg.png"。

    "bgm"：字典（选填）
        说明：主菜单背景音乐。进入主菜单时播放，离开主菜单时停止。
        "bgm"内的keys："bgm", "in", "out"

        "bgm"：字符串（必填，只要写了 menu.bgm 就必须有）
            "bgm"的内容解释：主菜单背景音乐文件路径（相对json），如："./res/audio/bgm_menu.mp3"。

        "in"：字符串（选填，默认直接播放）
            "in"的内容解释：音乐入场（开始播放）时的淡入效果，支持 "normal"（直接播放）与 "gradient"（渐变淡入）。

        "out"：字符串（选填，默认直接停止）
            "out"的内容解释：音乐退场（离开主菜单）时的淡出效果，支持 "normal"（直接停止）与 "gradient"（渐变淡出）。

    "change"：列表（选填）
        "change"的内容解释：主菜单出现的转场效果。格式为 [[r,g,b], "gradient"]，
        即一个由颜色和效果名组成的列表，程序取列表第2个元素（效果名）作为转场效果。
        第1个元素（颜色）当前未在代码中使用，仅作预留。
        目前支持的效果有：渐变 "gradient"。

    "title"：字典（选填）
        "title"的内容解释：主菜单标题图片，按语言标签给出图片路径。
        程序先取当前语言对应的图片，若无则回退到"zh"的图片，再无可取第一张。
        例如：{"zh": "./res/menu/title.png"}。

    "button"：字符串（必填）
        "button"的内容解释：主菜单按钮的普通样式图片路径，如："./res/menu/button.png"。
        注意：代码中直接索引 menu["button"]，若缺失会报错，因此只要写了 menu 就必须提供 button。

    "button_touched"：字符串（选填）
        "button_touched"的内容解释：主菜单按钮被鼠标悬停/按下时的样式图片路径，如："./res/menu/button_touched.png"。

    "text_rgb"：列表（选填）
        "text_rgb"的内容解释：主菜单按钮文字的颜色，RGB格式，三个0~255的整数，如：[255, 255, 255]。
        默认值为 [255, 255, 255]。

    "menu_pos"：字典（选填）
    说明：设置主菜单中标题与各按钮的位置与文字。
    "menu_pos"内的keys说明：可包含 "title" 与任意按钮标签（如 "qload", "start", "load", "settings", "quit"）。

    "title"：列表（选填）
        "title"内的元素解释：标题图片在主菜单背景上的位置坐标 [x, y]，
        坐标系基于主菜单背景图片，图片左上角为0点，x轴向右增加，y轴向下增加。
        例如：[54, 48]。

    <按钮标签>：列表（必填，如 "start"/"load"/"settings"/"quit"）
        说明：设置一个主菜单按钮。列表结构为：[位置, 文字字典, 附加配置(可选)]
        第1个元素：按钮图片在主菜单背景上的位置坐标 [x, y]。
        第2个元素：文字字典，按语言标签给出按钮文字，如：{"zh": "开始游戏", "en": "Start Game", "ja": "ゲーム開始", "ru": "Начать игру"}。
            程序取当前语言对应的文字，若无则取字典中第一个文字。
        第3个元素（可选）：附加配置字典，如 {"ui_mode": "default"}。
        目前内置支持的按钮标签及其功能：
            "qload"：继续游戏（快速加载）。点击后若存在存档则弹出确认框（外观取 ui.confirm_ui），确认后读取最新存档（同 F3，快速存档优先）并进入剧情；若没有任何存档则点击无反应（不弹确认框）。
            "start"：开始游戏，点击进入剧情。
            "load"：打开加载面板（读档界面）。其附加配置字典与底部菜单条 "save" 的配置结构相同（color/saves_color/saves_text_color/text_color/button_color），用于设置加载面板的外观，不填写则使用默认值。
            "settings"：打开设置面板（语言/分辨率切换等）。其附加配置字典（ui_mode/color/text_color/button_color）用于设置设置面板外观，不填写则使用默认值。
            "quit"：退出游戏。点击后弹出确认框（外观取 ui.confirm_ui，问题文字为"确认退出？"），确认后才真正退出。
        自定义的其他按钮标签目前不会被绑定功能（点击无反应），仅作展示。

"story_and_position"：字典（必填）
    说明：设置剧情内容、人物、背景等
    "story_and_position"内的keys："character_and_motion", "backgrounds", "bgm", "selection_button", "storyline_settings", "story"

    "character_and_motion"：字典（选填，缺失时场景中引用角色会报"角色未定义"）
        说明：设置有形象的人物
        "character_and_motion"内的keys说明：自定义的人物标签，例如: "girl", "congyu", "丛雨"

        <人物标签>：字典（必填）
            人物标签内的keys："name", "form", "face"

            "name"：字典（必填）
                说明：设置该人物标签在游戏中的称呼
                "name"内的keys说明：为"settings"中"language"所设定的语言标签，如在"language"中设置了{"zh": "中文", "en": "English"}，此字典的内容应为：{"zh": "丛雨", "en": "Murasame"}

                <语言标签>: 字符串（必填）
                    内容解释：设置该人物标签在游戏中不同语言的称呼

            "form": 字典（必填）
                说明：设置该人物的不同形态，并设置该形态所指向的图片文件路径
                "form"内的keys说明：自定义的形态标签，例如："校服", "工作", "校服2"

                <形态标签>：字符串（必填）
                    内容说明：该形态所指向的图片文件路径，如："校服": "./res/character/girl/uniform.png"

            "face"：字典（选填）
                说明：设置该人物的面部表情，并设置所指向的图片文件路径。你也可以直接在形态的图片上包含表情，并在后续剧情中直接调用该带表情的形态，从而不填写此部分。
                "face"内的keys说明：自定义的表情标签，例如："微笑", "脸红", "平常"

                <表情标签>：字符串（必填）
                    内容说明：该表情所指向的图片文件路径，如："脸红": "./res/character/girl/shy.png"

    "backgrounds": 字典（选填，缺失时场景中引用背景会报"背景未定义"）
        说明：设置不同背景的标签，并设置该背景所指向的图片文件路径
        "backgrounds"内的keys说明：自定义的背景标签，例如："学校", "教室", "公园"

        <背景标签>: 字符串（必填）
            内容说明：该背景所指向的图片文件路径，如："公园": "./res/bg/park.png"

    "bgm"：字典（选填）
        说明：设置剧情 BGM 的定义表。场景级 bgm 操作（见下方场景内 "bgm"）通过 id 引用此处的路径。
        "bgm"内的keys说明：自定义的 BGM 标签

        <BGM标签>：字符串（必填）
            内容说明：该 BGM 所指向的音频文件路径，如："bgm1": "./res/audio/bgm_1.mp3"

    "selection_button"：字典（选填）
        说明：设置选择场景中选项按钮的外观。缺省时使用默认按钮样式。
        "selection_button"内的keys："text_color", "normal", "touched"

        "text_color"：列表（选填，默认 [255, 255, 255] 白色）
            "text_color"的内容解释：选项按钮文字的颜色，RGB格式。

        "normal"：字符串（选填）
            "normal"的内容解释：选项按钮普通状态（未悬停）的图片路径（相对json），如："./res/ui/selection.png"。

        "touched"：字符串（选填）
            "touched"的内容解释：选项按钮悬停状态的图片路径（相对json），如："./res/ui/selection_touched.png"。

    "storyline_settings"：字典（选填，缺失时默认主线 "main"）
        说明：设置故事线配置：开局主线、选线判定阈值、各分支初始分。
        "storyline_settings"内的keys："main_storyline", "score_gap", "storyline_id_score"

        "main_storyline"：字符串（选填，默认 "main"）
            "main_storyline"的内容解释：主线标签（游戏开始首先播放的故事线），如："main"。

        "score_gap"：浮点数（选填，默认 0）
            "score_gap"的内容解释：选线判定阈值。judge 路由判定时，第一名与第二名的分数差 >= score_gap 才进入第一名的线，否则进入保底线（详见场景内 "next" 的 judge 格式）。

        "storyline_id_score"：字典（选填）
            说明：各分支线的初始分数（计分用）。选项的 "score" 会累加到对应线的分数上。
            "storyline_id_score"内的keys说明：故事线标签

            <故事线标签>：浮点数（必填）
                内容说明：该故事线的初始分数，如："main": 1.0

    "story"：字典（选填，但故事线标签必须对应此处一个key，否则该故事线无内容）
        说明：各故事线的剧情内容。若缺失或某故事线标签无对应内容，播放时打印"故事结束"。
        "story"内的keys说明：故事线标签（如 "main"、"cafe_girl"、"girl"、"end"）。
        开局主线由上方"storyline_settings"中"main_storyline"指定；其余线由选项"next"/场景"next"跳转进入（"end"为结局线）。

        <故事线标签>：字典（必填）
            说明：故事、剧情内容，以及场景、字幕的设定。注意，在"clear_all": false的情况下，上一页设置的场景在不再次设置的情况下，会继续存在，若重新设置了某部分，该部分的内容会被替换成新设置的内容（其中"bg"整体替换，"characters"按人物标签逐个替换：被重新设置的人物标签替换成新设置，未设置的其余人物保留）。具体可在第2部分的示例json解析中了解。
            字典内的keys说明：页数，从1开始

            <页数>：列表（必填）
                说明：设置该页的场景
                列表内元素说明：元素为字典，列表内有n个元素（字典），就代表有n个场景（n不可小于1）

                列表内的元素：字典（必填）
                    说明：场景的设置
                    字典内的keys："clear_all", "change", "bg", "characters", "chatbox", "content", "bgm", "audio", "selection", "next"

                    "clear_all": bool（选填，默认false；但每一个故事线的第一页的"clear_all"都必须为true）
                        说明：是否清空上一页场景中的内容，true为是，false为否。每一个故事线的第一页的"clear_all"都必须为true，否则会残留上一个故事线/页面的内容。

                    "change"：字符串或列表（选填）
                        "change"的内容说明：设置转场效果，默认直接变化
                        目前支持的效果有：
                            渐变  "gradient"
                        字符串写法：直接填效果名，如："change": "gradient"。
                        列表写法：两个元素，第一个为效果名，第二个为效果持续秒数（浮点数），如："change": ["gradient", 0.2]（渐变 0.2 秒）、"change": ["gradient", 2]（渐变 2 秒）。

                    "bg"：字符串或字典（选填）
                        "bg"的内容说明：设置背景，有两种写法。
                        字符串写法：内容应为上面"backgrounds"中所设置的背景标签，如："bg": "公园"。
                        字典写法：{"color": [r,g,b]} 纯色背景，即用 RGB 颜色填充整屏作为背景，如："bg": {"color": [0, 0, 0]}（黑色背景）。

                    "characters"：字典（选填）
                        说明：设置有形象的角色上场
                        "characters"内的keys说明：为上面"character_and_motion"中所设置的人物标签；也可使用空字符串""作为key（见下方说明）

                        <人物标签>：字典（必填）
                            说明：设置上场人物的形态、位置、表情、缩放、动画等
                            字典内的keys："form", "pos", "face", "zoom", "animate"

                            "form"：字符串（必填）
                                "form"的内容说明：为上面"character_and_motion"里，此人物标签里"form"所设置的形态标签

                            "pos": 列表（必填）
                                "pos"内的元素解释：列表内应有两个值，分别对应形态图片在背景图片上的坐标x和y，坐标基于背景的图片，图片左上角为0点，x轴像右增加，y轴向下增加，格式如此：[320,80]，代表将形态图片放在背景图片上位于(320, 80)的像素上。

                            "face"：列表或字符串（必填）
                                "face"的内容解释：有两种写法。
                                列表写法：有两个元素，第一个为字符串，内容为上面"character_and_motion"里，此人物标签里"face"所设置的表情标签；第二个为列表，列表内应有两个值，分别对应表情图片在形态图片上的坐标x和y，坐标基于形态的图片，图片左上角为0点，x轴像右增加，y轴向下增加，格式如此：[0,0]，代表将表情图片放在形态图片上位于(0, 0)的像素上。整个列表格式如此：["脸红",[0,0]]。
                                注意：代码中 setup_character 只取列表第1个元素（表情标签），第2个元素（偏移坐标）当前版本未使用，表情固定绘制在形态图片左上角(0,0)处，该坐标字段为预留。
                                字符串写法：直接填写表情标签，如："face": "平常"。
                                注意：代码中直接索引 char_info["face"]，若缺失会报错，因此只要写了 characters 就必须提供 face。

                            "zoom"：浮点数（选填）
                                "zoom"的值说明：设置人物的缩放，默认1.0，小于（<）1.0为缩小，大于（>）1.0为放大。

                            "animate"：列表（选填）
                                说明：设置人物在此场景内的动画
                                列表内元素说明：元素为列表，每个列表为一组动画，组内各段动画同时播放，组间顺序播放。

                                列表内的元素（一组动画）：列表（必填）
                                    组内元素：字典，组内可以有多段动画，它们同时播放。

                                    字典内的keys："time", "zoom", "move"

                                    "time"：浮点数（选填，缺失或为0则该段动画被跳过，建议填写）
                                        "time"的值说明：动画持续的时间，单位为秒。若缺失或为0，该段动画不执行（直接跳过）。

                                    "zoom": 浮点数（选填）
                                        "zoom"的值说明：设置缩放动画，在动画持续时间内（"time"）将人物的缩放从上面"zoom"的值缩放到此值。若是非第一组动画，则从上一组动画结束后的值缩放到此值。具体可在第2部分的示例json解析中了解。

                                    "move": 列表（选填）
                                        "move"内的元素解释：元素为列表，元素数量无具体上限，各个列表内填有两个数值，对应坐标x和y，x轴像右增加，y轴向下增加，该坐标为基于自己的相对坐标。在动画持续时间内（"time"）将人物按顺序移动到相对坐标上。如此例：将人物向左移动10，然后向下移动10，再往右移动10，最后向上移动10，此时应填入：[[-10,0],[0,10],[10,0],[0,-10]]

                        空字符串""人物标签（key 为 ""）：字典（选填）
                            说明：无图空角色——不加载任何图片，仅用 "animate" 计算动画总时长作为本场景的停留等待（视觉上画面保持当前状态动画时长）。仅用于无文本且需要停留的场景（如黑屏转场页）。
                            字典内的keys："animate"（选填，格式同上）

                    "chatbox"：字典（选填）
                        说明：控制对话框（以及名字/字幕显示区域）的显示与隐藏
                        "chatbox"内的keys："visible", "change"

                        "visible"：bool（必填）
                            "visible"的值说明：是否显示对话框，true为显示，false为隐藏。

                        "change"：字符串（选填）
                            "change"的内容说明：对话框显隐切换的转场效果，目前支持的效果有：
                                渐变  "gradient"

                    "content"：字典（选填）
                        说明：设置对话内容。不填写的场景（如纯背景切换页）会直接标记文本与音频完成，自动进入下一个场景/等待翻页。
                        "content"内的keys："speaking"/"speaking_name", "words"

                        "words"：字典（必填，只要写了 content 就必须有）
                            说明：设置每一个语言标签对应语言的对话字幕，具体可在第2部分的示例json解析中了解。
                            注意：代码中 display_dialog 直接索引 content["words"]，若缺失会报错，因此写了 content 就必须提供 words。
                            字幕取当前语言对应的文字，若无则回退到 "zh"，再无可取空字符串。
                            "words"内的keys说明：为上面"settings"中"language"里设置的语言标签

                            <语言标签>: 字符串（必填）
                                内容说明：对话在该语言标签所对应语言下的字幕

                        "speaking"：字典 / "speaking_name"：字符串 （两者均选填，可都不填；都不填则名字显示为空）
                            说明：设置说话人名字。若同时填写两者，"speaking_name" 优先。
                            "speaking"说明：设置每一个语言标签对应语言的说话人名字，具体可在第2部分的示例json解析中了解。
                            名字取当前语言对应的文字，若无则回退到 "zh"，再无可取空字符串。
                            "speaking"内的keys说明：为上面"settings"中"language"里设置的语言标签

                            <语言标签>：字符串（选填）
                                内容说明：说话人在该语言标签所对应语言下的名字（可为空字符串""，表示无名字）

                            "speaking_name"说明：若说话人在上面的"character_and_motion"中有所设置，可在此使用所设置的人物标签直接调用
                            "speaking_name"的内容说明：上面"character_and_motion"中所设置的人物标签。程序从该人物的"name"字典中取当前语言的称呼，若无则回退"zh"，再无可取空字符串。

                    "bgm"：列表（选填）
                        说明：场景级背景音乐操作，按顺序执行。id 来自上面"story_and_position"中"bgm"定义表（也可用空字符串""表示停止当前 BGM）。
                        列表内元素说明：元素为字典，每个字典为一次 BGM 操作。
                        字典内的keys："id", "in", "out", "delay"

                        "id"：字符串（必填）
                            "id"的内容说明：BGM 标签（来自"story_and_position"中"bgm"定义表）；空字符串""表示停止当前正在播放的 BGM。

                        "in"：字符串或列表（选填）
                            "in"的内容说明：开始播放时的入场效果，支持 "normal"（直接播放）与 "gradient"（渐变淡入）；也可填列表 ["gradient", 秒数] 指定淡入时长。

                        "out"：字符串或列表（选填）
                            "out"的内容说明：停止时的退场效果，支持 "normal"（直接停止）与 "gradient"（渐变淡出）；也可填列表 ["gradient", 秒数] 指定淡出时长。

                        "delay"：浮点数（选填，默认 0）
                            "delay"的值说明：延迟执行秒数。大于 0 时该操作延迟到点执行，翻页不影响已排定的延迟操作。

                    "audio"：字典（选填）
                        说明：场景级语音/音效配置。播放方式：组内并行、组间顺序，全部播完标记音频完成（可点击跳过）。
                        "audio"内的keys："json_mode", "play_in_order"

                        "json_mode"：字符串（选填，默认 "normal"）
                            "json_mode"的内容说明：音频配置的解析模式，支持：
                            - "normal"："play_in_order" 为多语言字典，只取当前语言的音频列表，该语言无文件则不播放。
                            - "judge"  ："play_in_order" 为模板二维列表，文件名中的 <line>/<page>/<lang_id> 会被替换为当前线/页/语言；当前语言文件缺失时回退上面"settings"中"default_audio_lang_id"指定的语言。

                        "play_in_order"：字典或二维列表（必填，只要写了 audio 就必须有）
                            "play_in_order"的内容说明：音频文件列表。
                            json_mode=normal 时：多语言字典，keys 为语言标签，值为二维列表（组间顺序、组内并行），如：{"zh": [["./res/audio/a_zh.wav"]], "en": [["./res/audio/a_en.wav"]]}。
                            json_mode=judge 时：模板二维列表，如：[["./res/audio/audio_girl_<line>_<page>_<lang_id>.wav"]]。

                    "selection"：字典（选填）
                        说明：设置选择场景（选项页）。此场景只显示选项，等待玩家点击后跳转。
                        "selection"内的keys："change", "selection"

                        "change"：字符串（选填）
                            "change"的内容说明：选项出现的转场效果，目前支持：渐变 "gradient"。

                        "selection"：列表（必填）
                            说明：选项列表。
                            列表内元素说明：元素为字典，每个字典为一个选项。
                            字典内的keys："text", "score", "next"

                            "text"：字典（必填）
                                "text"的内容解释：选项文字（按语言标签），如：{"zh": "是的，我经常来", "en": "Yes, I come here often"}。

                            "score"：列表（必填）
                                "score"的内容解释：两个元素，第一个为故事线标签，第二个为分数值。选中该选项后，此分数累加到对应故事线（计分用，影响后续 judge 判定），如：["main", 0.5]。

                            "next"：字典（必填）
                                "next"的内容解释：选择该选项后的跳转路由，格式同下方场景内 "next"（如 {"direct": ["main", "18"]}）。

                    "next"：字符串或字典（选填）
                        说明：场景播完后的跳转路由（本页/本场景结束后跳到哪里）。不填写则按顺序播放下一个场景/下一页。
                        支持的格式：
                        - 字符串 "end"：表示整个剧情的最后一页，播完自动返回主菜单。
                        - 字典 {"direct": [线, 页]}：直接跳转到指定故事线的指定页，如：{"direct": ["main", "41"]}。
                        - 字典 {"judge": [[候选线列表], [保底线]]}：计分判定路由。候选线列表可含多条 [线, 页]；保底线固定一条 [线, 页]。判定时取各线当前分数（初始值来自"storyline_settings"中"storyline_id_score"，选项"score"会累加）的第一名：第一名与第二名分差 >= "score_gap" 则进入第一名的线，否则进入保底线。如：{"judge": [[["girl", "1"]], [["main", "41"]]]}。

## 存档系统（.gpsave）

- 格子存档：`saves/{标题}_{识别码}_SLOT{index}.gpsave`，index 为格子编号（保存面板第 1 行 0-3、第 2 行 4-7，第 2 页 8-15，依此类推）。
- 快速存档：`saves/{标题}_{识别码}_QSAVE.gpsave`，index 固定为 -1，不在保存面板显示，读档（F3）时排最前。
- 存档内容为 pickle 序列化的 11 元素列表：标题、识别码、缩略图 PNG、storyline 配置、当前故事线、当前页-1、说话者、台词（多语言 dict）、日期、时间、格子 index。
- 设置文件：`saves/{标题}_{识别码}_SETTINGS.gpsetting`（标题、识别码、分辨率、语言）。

### 保存面板 / 加载面板

保存面板与加载面板为同一个面板组件（SavePanel），外观由 `ui.bottom_menu.save`（保存）或主菜单 `menu.menu_pos.load` 的附加配置（加载）决定，两者配置结构相同。

- **保存面板**（剧情中点击底部"保存"按钮，或按 F2 快速存档）：
  - 面板显示 8 个存档格子（2 行 × 4 列），每格显示缩略图、台词、日期时间；空格子显示灰色 "SAVE" 字样。
  - 点空格 → 直接保存到该格；点有存档的格子 → 弹出"确认覆盖？"，确认后删旧存新。
  - 有存档的格子右下角有垃圾桶按钮，点击弹出"确认删除？"；点"确认"删除该存档，点"取消"或点击其他区域退出确认。
- **加载面板**（主菜单点击"加载存档"按钮）：
  - 布局与保存面板相同，但左上角标题为"加载游戏"，底部工具条无加号按钮；格子右下角同样有垃圾桶按钮，可删除存档（删除确认机制与保存面板相同）。
  - 点有存档的格子 → 弹出"确认读取？"，确认后读档并进入剧情（先渐变至 transition_color 再进场景）；空格无操作。
- **分页**：面板底部工具条左侧为 ◀ 翻页 ▶ 与页数"当前页/总页"，右侧为"主菜单"与"返回"按钮。每页 8 个格子，页数由最大存档格子 index 推算（index 8-15 为第 2 页，依此类推），"+" 按钮可增加一页（仅保存面板有）。翻页为环形：第 1 页向左翻到最后一页，最后一页向右翻回第 1 页。
- 面板打开时底部菜单条与主菜单按钮隐藏，关闭后恢复；打开面板会暂停自动播放/快进。

### 底部菜单条按钮

剧情中底部菜单条从右到左依次为：

1. **日志**：打开日志面板（显示本场剧情已显示过的台词，按当前语言翻译）。
2. **设置**：打开设置面板（语言切换、分辨率切换，设置会保存到 .gpsetting 文件）。
3. **快进（▷▷）**：快速跳过剧情（每页只搭建第一个场景、不显示对话、立即翻页）。
4. **自动播放（▷）**：自动推进剧情。
5. **保存**：打开保存面板。
6. **快速保存（Q.Save）**：直接保存到快速存档槽（覆盖旧快速存档）。

快进与自动播放互斥，打开其一自动关闭另一个；打开面板时两者暂停，返回剧情后继续。

### 热键

- 空格 / 回车 / 鼠标左键：推进剧情（逐字显示中点击则完成显示）
- A：自动播放开关
- S：快进开关
- F2：存档
- F3：读最新档（快速存档优先）
