# GalPie
语言： [**中文**] | [English](./README_EN.md)
<br><br>
基于PySide6的Galgame制作器/阅读器<br>
<b>(仍在开发中)</b>
<br><br>
主程序：GalPie.py<br>
目前可读取按照规则编写的剧情json文件来进行游戏。<br>
（编写规则可查看 **doc** 文件夹中的 **剧情json规则.txt**（英文版：**Story JSON rules.txt**），亦可参考 **story** 文件夹中的 **sample_create.json** 进行编写）<br>
<br>
将剧情json文件放入 **story** 文件夹内，程序启动时将自动读取并开始游戏。<br>
若剧情中填写了 **menu**（主菜单），则启动后先显示主菜单；未填写则直接进入剧情。<br>
<br>

## 主菜单<br>
启动时若检测到剧情配置了 **menu**（主菜单），会先显示主菜单，支持以下按钮（需在 **menu.menu_pos** 中配置）：<br>
- **继续游戏**（qload）：有存档时弹出确认框，确认后读取最新存档（快速存档优先）并进入剧情；无存档时点击无反应<br>
- **开始游戏**（start）：进入剧情<br>
- **加载存档**（load）：打开加载游戏界面，可读取该剧情的格子存档<br>
- **设置**（settings）：打开设置面板（语言/分辨率）<br>
- **退出**（quit）：弹出确认框，确认后退出程序<br>
<br>

## 底部菜单条<br>
剧情中窗口底部可显示预设菜单条（由剧情的 **ui.bottom_menu** 控制），从右到左依次为：<br>
<b>⊙</b>（隐藏开关：隐藏对话框与底部菜单，任意位置点击恢复）→ <b>日志</b>（历史对话）→ <b>设置</b>（语言/分辨率）→ <b>快进(▷▷)</b> 开关 → <b>自动播放(▷)</b> 开关 → <b>加载</b>（打开加载界面）→ <b>保存</b>（打开保存界面）→ <b>Q.Load</b>（快速加载：确认后读取最新存档）→ <b>Q.Save</b>（快速保存）。<br>
<b>⊙</b> 按下后对话框与底部菜单（含菜单条本身）全部消失，剧情照常推进；再按任意位置（左键或右键）恢复显示，对话框按进入隐藏前的可见性恢复。<br>
快进与自动播放互斥（打开其一自动关闭另一个）；打开任意面板时两者会暂停，返回剧情后继续。<br>
菜单条颜色、按钮颜色、各面板配色均可由剧情json配置（详见 **doc** 文件夹规则文档）。<br>
<br>

## 设置面板<br>
剧情中点击底部菜单的 **设置** 按钮，或主菜单中配置了 **settings** 按钮时点击该按钮，可打开设置面板：<br>
- **语言**：切换游戏语言（选项来自剧情 json 的 settings.language；预设界面文字支持中/英/日，超出范围回退英文；剧情内对话按剧情提供的翻译显示）<br>
- **分辨率**：切换窗口分辨率（选项来自剧情 json 的 settings.window_size，末尾附加"全屏"选项；未配置时使用内置默认列表）<br>
设置修改后会自动保存到设置存档文件，下次启动同一剧情时自动恢复。<br>
<br>

## 保存 / 加载界面<br>
剧情中点击底部菜单的 **保存** 按钮打开保存界面，主菜单点击 **加载存档** 打开加载界面（两界面共用一套格子界面）：<br>
- **格子存档**：每页 8 个格子（2 行 × 4 列），点空格直接保存到该格；点已有存档的格子会先询问"确认覆盖？"，确认后覆盖保存<br>
- **删除存档**：有存档的格子右下角有垃圾桶按钮，点击后询问"确认删除？"，确认后删除该存档<br>
- **分页**：左下角 ◀ ▶ 翻页（环形翻页），显示"当前页/总页"；保存界面有 **+** 按钮可新增一页，加载界面没有<br>
- **加载界面**：点已有存档的格子会询问"确认读取？"，确认后读取该存档并进入剧情（快速存档不出现在格子中）<br>
- 界面右下角有 **主菜单**（返回主菜单）与 **返回**（返回剧情）按钮<br>
<br>

## 日志面板<br>
点击底部菜单的 **日志** 按钮打开，可查看本局游戏已播放的对话记录（按当前语言显示），返回按钮关闭面板。<br>
<br>

## 存档系统<br>
存档文件存放在 **saves** 文件夹内，按剧情自动隔离（文件名前缀为 剧情标题_识别码）：<br>
- **格子存档**：`{标题}_{识别码}_SLOT{编号}.gpsave`（编号即格子号，如 0-7）<br>
- **快速存档**：`{标题}_{识别码}_QSAVE.gpsave`（F3 读档时优先读取）<br>
- **设置存档**：`{标题}_{识别码}_SETTINGS.gpsetting`（保存语言/分辨率设置）<br>
不同剧情的存档互不干扰；<b>不同剧情请务必设置不同的 identify_code</b>（识别码），否则会被视为同一剧情而共用存档。<br>
<br>
