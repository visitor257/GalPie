# GalPie
语言： [**中文**] | [English](./README_EN.md)
<br><br>
基于PySide6的Galgame制作器<br>
<b>(仍在开发中)</b>
<br><br>
主程序：GalPie.py<br>
目前可读取按照规则编写的剧情json文件来进行游戏。<br>
（编写规则可查看 **doc** 文件夹中的 **剧情json规则.txt**（英文版：**Story JSON rules.txt**），亦可参考 **sample** 文件夹中的 **sample_create.json** 进行编写）<br>
<br>
将剧情json文件放入 **story** 文件夹内，程序启动时将自动读取并开始游戏。<br>
若剧情中填写了 **menu**（主菜单），则启动后先显示主菜单，点击 **开始游戏** 按钮进入剧情；未填写则直接进入剧情。<br>
<br>

## 游戏中的操作<br>
<table>
<tr>
<td>[Space] / [Enter] / 鼠标左键</td>
<td>推进剧情（文本未显示完时点击可立即显示完整文本）</td>
</tr>
<tr>
<td>[A]</td>
<td>自动播放 开关</td>
</tr>
<tr>
<td>[S]</td>
<td>快进 开关（模拟长按空格，自动快速推进剧情）</td>
</tr>
<tr>
<td>[F2]</td>
<td>快速存档（储存在 <b>saves</b> 文件夹内）</td>
</tr>
<tr>
<td>[F3]</td>
<td>快速读档（读取最新存档）</td>
</tr>
<tr>
<td>[Esc]</td>
<td>关闭设置面板</td>
</tr>
</table>
<br>
剧情中窗口底部可显示预设菜单条（由剧情的 **ui.bottom_menu** 控制），右侧依次为：<br>
<b>设置</b> 按钮（打开设置面板，可切换语言/分辨率等）→ <b>快进(▷▷)</b> 开关 → <b>自动播放(▷)</b> 开关。<br>
快进与自动播放互斥（打开其一自动关闭另一个）；打开设置面板时两者会暂停，返回剧情后继续。<br>
<br>

## 设置面板<br>
剧情中点击底部菜单的 **设置** 按钮，或主菜单中配置了 **settings** 按钮时点击该按钮，可打开设置面板：<br>
- **语言**：切换游戏语言（选项来自剧情 json 的 settings.language，界面文字支持中/英/日，超出范围回退英文）<br>
- **分辨率**：切换窗口分辨率（选项来自剧情 json 的 settings.window_size，末尾附加"全屏"选项；未配置时使用内置默认列表）<br>
